# Omicron - a programming language, that compiles into cron.
This repository contains the source code of the compiler and its documentation.

### Code example
```omicron
every friday at 20:00 sh("/usr/bin/backup.sh")
```

### Why you should use Omicron?
 - Human-readable: schedules are written in plain English, not cryptic cron expressions.
 - Easy to use: no need to memorize * */5 1,15 * 3 — just write what you mean.
